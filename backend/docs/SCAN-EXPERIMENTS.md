## 月账单实验

月账单的 QPS 指每次 HTTP 请求，不是每秒电表数。
每个正常电表至少需要 4 次会话/页面请求，再加每个可见月份 1 次请求。

## 可复现命令

在 Git Bash 中从 `backend/` 执行：

```bash
bash scripts/scan_probe.sh 10 0.5 1
```

脚本使用一次性 PostgreSQL 17。
脚本依次执行迁移、清单导入、历史快照导入和受控扫描。
输出聚合 JSON 后删除容器。
默认拒绝超过 200 表的探测。
